# front

SPA на Bun + React. Сервер отдаёт статику и проксирует `/api/*` на бэкенд.

## Установка

```bash
bun install
```

## Разработка

```bash
bun dev
```

## Почему bun?

Скорость.

## Почему React SPA?

См. выше.

## Продакшен

```bash
bun start
```

## Переменные окружения

| Переменная     | По умолчанию            | Описание                          |
| -------------- | ----------------------- | --------------------------------- |
| `PROXY_TARGET` | `http://localhost:8000` | Куда проксировать запросы `/api/*` |
| `PORT`         | `3000`                  | Порт сервера                      |

Пример:

```bash
PROXY_TARGET=https://backend.example.com bun dev
```
